# The Travel Tech SaaS - E-Ticaret Otomasyonu 🚀

Bu proje, seyahat teknolojileri (akıllı valizler, güç sistemleri vb.) üzerine kurgulanmış, baştan sona Laravel ile geliştirilmiş tam kapsamlı bir e-ticaret platformudur.

## 🌟 Öne Çıkan Özellikler
*   **Dinamik Müşteri Vitrini:** Ürün listeleme, kategori filtreleme ve detay sayfaları.
*   **Alışveriş Sepeti (Session):** Kesintisiz ve güvenli sepet yönetimi.
*   **Sipariş (Checkout) Sistemi:** Sepetteki ürünlerin müşteri bilgileriyle veritabanına işlenmesi.
*   **Admin Paneli:** Kategorileri, ürün stoklarını ve gelen siparişlerin durumunu tek merkezden yönetme (CRUD işlemleri).

## 💻 Kullanılan Teknolojiler
*   Backend: **Laravel 11, PHP 8**
*   Frontend: **Blade, Bootstrap 5**
*   Veritabanı: **MySQL**
